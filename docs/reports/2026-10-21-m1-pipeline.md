# M1 视觉等价管线验证报告

- 日期：2026-10-21
- 目标：打通 `ScreenCaptureKit → VideoToolbox 硬编 → 雷雳 TCP → VideoToolbox 硬解 → Metal 上屏` 完整管线，并在 60 fps、端到端延迟与画质（SSIM > 0.98）三项指标上完成编码器选型与验收。

## 1. 管线架构

```text
[被控端] ScreenCaptureKit 采集 ──► VideoToolbox 硬件编码 ──► TCP (TCP_NODELAY, 20B 帧头)
                                                                      │
[主控端] Metal (MTKView) 渲染  ◄── VideoToolbox 硬件解码 ◄────────────┘
```

| 模块 | 实现要点 |
|---|---|
| 采集 | ScreenCaptureKit，`queueDepth = 8`，`minimumFrameInterval = 0`，420v 像素格式 |
| 编码 | VideoToolbox 硬件加速，对比测试 HEVC、H.264 与 ProRes 422 |
| 传输 | 裸 TCP + `TCP_NODELAY`，20 字节大端帧头 + `format` / `frame` 数据包 |
| 解码 | VideoToolbox 实时硬解，输出 `CVPixelBuffer`（IOSurface 零拷贝绑定 Metal 纹理） |
| 呈现 | Metal `MTKView`，双平面 YCbCr BT.709 片段着色器（同时支持 8-bit 与 10-bit） |

## 2. 硬件编码器实测对比（4K 3840×2160 真实桌面）

在被控端（M4 Pro）与主控端（M5 Pro）之间通过雷雳网桥直连实测三种硬件编码器：

| 编码器 | 吞吐帧率 | 平均编码延迟 | 码率 | 评估结论 |
|---|---|---|---|---|
| HEVC Main（硬件） | 60.0 fps | 22.9 ms | 6–17 Mbps | 编码器内部管线延迟固定约 20–23 ms，保留为低带宽回退选项 |
| H.264 High（硬件） | 55.0 fps | 57.7 ms | 2.5 Mbps | 编码延迟过高且帧率不达标，排除 |
| **ProRes 422（硬件）** | **59.9 fps** | **8.85–9.16 ms** | **561–658 Mbps** | **主路径**：编码延迟低于 10 ms，全 I 帧无帧间依赖，占雷雳桥带宽约 1% |

## 3. ProRes 422 端到端延迟与吞吐

切换默认编码器为 ProRes 422 后，客户端全屏 1× 3840×2160 实测输出：

```text
server: fps=60.0 dropped=0 encLat=8.56~8.67ms bitrate=598Mbps
client: decode fps=60.4 failed=0
        recv p50=10.5ms p95=11.5ms
        decodeLatency p50=12.1ms p95=13.2ms
        render p50=19.4ms p95=27.6ms (capture→present)
        switch display mode -> 3840x2160 1x: ok (attempt 1)
```

- **帧率**：服务端编码 60.0 fps（0 丢帧），客户端解码 60.4 fps；
- **延迟**：`capture→decode` P95 **13.2–13.7 ms**，`capture→present` P95 **18.2–27.6 ms**（均低于 33 ms 预算）。

## 4. 像素等价（SSIM / PSNR）验收

使用包含中英文小字号文本、彩条、细网格与高频棋盘格的 `6016×3384` 标准测试图，将本地参考图与客户端抓帧进行逐区域比对：

| 测试区域 | SSIM | PSNR | 说明 |
|---|---|---|---|
| **全图（去菜单栏）** | **0.9839** | 30.20 dB | **通过**（目标 SSIM > 0.98） |
| **文字区域** | **0.9904** | 30.31 dB | **通过**，文字边缘锐利无重影 |
| **细网格区域** | **0.9871** | 37.44 dB | **通过** |
| 2px/4px 彩色高频棋盘格 | 0.9622 | 24.27 dB | 受限于 ScreenCaptureKit 4:2:0 采集源的色度下采样 |
