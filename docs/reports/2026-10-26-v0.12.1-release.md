## 发布内容

- 修复 v0.12 的全屏工具栏点击穿透：本地输入监听不再把工具栏浮层窗口的事件当成视频点击，非 key 首击先本地激活，画面上沿以上按屏幕坐标排除（提交 `4bbb402`，[报告第 4 节](2026-10-26-audio-route-and-fullscreen-chrome.md#4-v012-回归全屏工具栏点击穿透)）。
- 新增 `InputChromeRoutingTests`，钉住“画面上沿以上是 chrome、顶边及以下是画面”的边界。
- 版本号默认值更新为 `0.12.1 / 4`，README / README_EN / releasing / open-items 同步；XCTest 数量更新为 80。

## 验证命令与结果

```bash
# 发布前（b6df70e）本地验证
swift build -c release
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
# 80 项：79 通过、1 跳过（无音频输出设备用例）
.build/release/boltkvm selftest   # SELFTEST OK
.build/release/boltkvm cryptotest # cryptotest PASS (1000 frames, 3 tamper cases)

# 本地盖章与打包
BOLTKVM_VERSION=0.12.1 BOLTKVM_BUILD=4 ./Packaging/build-app.sh
# ==> version 0.12.1 (4)
# CFBundleShortVersionString=0.12.1, CFBundleVersion=4, Signature=adhoc
```

main CI 与 Release 工作流均成功。Release 产物下载后复核：

```bash
V=0.12.1
mkdir -p /tmp/boltkvm-$V-release && cd /tmp/boltkvm-$V-release
gh release download v$V --repo haitau/boltkvm --pattern 'BoltKVM-'$V'.zip*'
cat BoltKVM-$V.zip.sha256
# 6c850861e4bad999c9367c05ac4dfa9c8269ca4db4d444d8d70454f4b0a402b9  BoltKVM-0.12.1.zip
shasum -a 256 -c BoltKVM-$V.zip.sha256   # BoltKVM-0.12.1.zip: OK
unzip -q BoltKVM-$V.zip
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' BoltKVM.app/Contents/Info.plist # 0.12.1
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' BoltKVM.app/Contents/Info.plist            # 4
codesign -dv BoltKVM.app 2>&1 | grep Signature # Signature=adhoc
```

`.sha256` 只包含文件名，没有 v0.12 首次发布时的 `out/` 前缀；`shasum -c` 在下载目录直接通过。

## 证据分级

- 【事实】标签、Release URL、工作流 run id、资产名与大小、`Info.plist` 版本、SHA-256 值、`shasum -c` 通过、签名类型，均来自本次实际命令输出与 GitHub API。
- 【事实】发布前 main CI（40309108845）与 Release 工作流（40309358354）均成功；本地 `swift test` 80 项（1 跳过）、selftest、cryptotest 通过。
- 【推断】Release 包的 `CFBundleVersion=4` 是本次 Release 工作流的 `GITHUB_RUN_NUMBER`，与本地显式覆盖的 4 一致。
- 【未经核实】没有在另一台 Mac 上解压并首次启动该 Release 包；ad-hoc 签名下的 TCC 首次授权流程未在本次发布中复测。
- 【未经核实】本机全屏工具栏的完整人工复测仍覆盖有限：172 测试包上锁定指针点击工具栏顶部/下沿无转发计数增长，但所有按钮、不同缩放/多显示器组合未逐一验证。
