## 发布后发现并修复的校验和问题

v0.12 首次发布的 `BoltKVM-0.12.zip.sha256` 内容为：

```text
e55f6b3d...  out/BoltKVM-0.12.zip
```

用户把 zip 与 `.sha256` 下载到同一目录后执行 `shasum -a 256 -c` 会因 `out/` 前缀失败。已在 main 修复 `release.yml`（在 `out/` 目录内生成校验和，只写文件名，提交 `b0a2bc8`），并用一次性工作流把 v0.12 的 `.sha256` 资产替换为：

```text
e55f6b3d0a943522d1aed021d6bf08d68d7c61985caba6c009aa5dd3f7ef9277  BoltKVM-0.12.zip
```

复核 `shasum -a 256 -c` 输出 `BoltKVM-0.12.zip: OK`。`v0.12` 标签仍指向发布提交 `d1f6f72`，未移动；`b0a2bc8` 只影响 main 上后续发布的校验和生成。
