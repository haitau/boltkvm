# M2 输入链路报告：CGEventTap → 雷雳 → CGEvent 注入

- 日期：2026-10-21
- 目标：主控端全屏捕获键鼠（含系统快捷键、修饰键、连续滚动 phase），通过雷雳传输，在被控端注入；与 M1 视频管线同时运行。
- 结论：**核心输入链路跑通**；⌘Tab、⌘Space、文字输入、鼠标点击、滚动 phase 与退出热键均验证。⌃↑ 受前台 app 快捷键冲突影响，Secure Input 与触控板手势仍是已知限制。

## 1. 架构

```text
MacBook                                       Mac mini
CGEventTap (.cgSessionEventTap)               TCP read thread
  key/mouse/scroll → InputEvent (48B) ──────► InputEvent.decode
  归一化坐标                                     CGEvent.post(.cghidEventTap)
  swallow 本地事件                              键盘 / 鼠标 / 滚动 phase
```

- 客户端在 `--render --input` 时安装 event tap；tap 返回 `nil`，本地不再响应。
- 输入包走 M1 同一条 TCP（全双工）；输入方向与视频方向独立，不共享发送队列。
- 坐标：客户端窗口内容归一化到 `[0,1]`，服务端乘以被控端 `CGDisplayBounds`。
- 退出：`⌃⌥⌘Q` 停止 tap、显示光标并终止客户端。
- 单输入源：服务端一次只接受一个客户端连接，拓扑上不存在第二写入者。

## 2. TCC

| 端 | 权限 | 结果 |
|---|---|---|
| MacBook（DSH 进程） | Accessibility / Input Monitoring / Post Event | true |
| mini（GUI Terminal 启动 server） | Accessibility / Post Event | true |

SSH 直接启动的进程没有这些权限；服务端必须从已授权的 GUI app 启动（本次为 Terminal）。

## 3. 验证

### ⌘Space + 文字

- 客户端捕获 ⌘Space，本地未打开 Spotlight；被控端打开 Spotlight。
- 继续注入 `hello`，被控端 Spotlight 显示 `hello—world` 搜索结果。
- 证明：系统快捷键捕获、修饰键、keyCode 注入、文字顺序。

### ⌘Tab

- 本地未切换 app；被控端弹出 app switcher，截图可见。
- 证明：全局系统快捷键在 head-insert session tap 被截获并转发。

### 鼠标点击

- 注入鼠标移动到左上角并左键点击；被控端 Apple 菜单展开。
- 证明：归一化坐标映射、mouseMoved、leftMouseDown/Up。

### 连续滚动

服务端日志：

```text
scroll 1 phase=1 momentum=0 dx=0.0 dy=-40.0
scroll 3 phase=2 momentum=0 dx=0.0 dy=-40.0
scroll 10 phase=4 momentum=0 dx=0.0 dy=-40.0
```

`phase=1` began、`2` changed、`4` ended 原样到达注入端。

### 退出热键

- 注入 `⌃⌥⌘Q` 后客户端日志 `input: capture stopped sent=...`，客户端提前终止，光标恢复。
- 证明 tap 的紧急释放路径可用。

### 与视频并行

一次 18 秒测试中：

```text
video: decode 60.3fps, recv p95 11.7ms, render p95 27.8ms
input: sent 143 events, server injected 120+
```

视频与输入互不阻塞。

## 4. 已知限制

- `⌃↑`：Finder / Terminal 会把 Control-Up 当作自身快捷键，Mission Control 不出现；这是前台 app 的快捷键冲突，不是 tap 丢失。⌘Tab / ⌘Space 这类全局快捷键正常。
- Secure Input 输入框（密码框）无法完整转发，属于预期限制。
- 触控板手势、Force Touch、三指拖移未实现；当前只转发离散鼠标/滚动事件。
- keyCode 按 US 键盘布局传输；两端布局不同会有偏差。
- 双击的 `clickState` 目前固定为 1；4/5 号侧键统一按 center button 注入，属 M2 基础版限制。
- tap 的 session 级位置可能被个别 app 级快捷键抢先；后续可按需增加 HID tap 或应用例外。
