# M2 输入链路报告：CGEventTap → 雷雳 → CGEvent 注入

- 日期：2026-10-21
- 目标：主控端捕获键鼠（含系统快捷键、修饰键、连续滚动 phase），经雷雳传输至被控端注入，并与 M1 视频管线并行运行。
- 结论：**核心输入链路跑通**；⌘Tab、⌘Space、文字输入、鼠标点击、滚动 phase 与退出热键均通过验证。

## 1. 架构

```text
主控端                                         被控端
CGEventTap (.cgSessionEventTap)               TCP read loop
  key/mouse/scroll → InputEvent (48B) ──────► InputEvent.decode
  归一化坐标                                     CGEvent.post(.cghidEventTap)
  吞掉本地事件                                   键盘 / 鼠标 / 滚动 phase
```

- 客户端在 `--render --input` 模式下安装 event tap；tap 返回 `nil` 吞掉本地事件。
- 输入包复用视频 TCP 全双工连接，收发方向独立。
- 坐标：客户端窗口内容归一化到 `[0, 1]`，服务端映射至被控端目标显示器 `CGDisplayBounds`。
- 退出：`⌃⌥⌘Q` 停止 tap、恢复光标并退出客户端。
- 单输入源：服务端同一时刻只服务一个活跃客户端连接。

## 2. TCC 权限

| 端 | 权限 | 结果 |
|---|---|---|
| 主控端 | Accessibility / Input Monitoring / Post Event | true |
| 被控端（GUI 终端启动） | Accessibility / Post Event | true |

SSH 直接启动的进程不具备上述 TCC 权限，服务端需由已获授权的 GUI 应用或 App bundle 启动。

## 3. 验证

### ⌘Space + 文字

- 客户端捕获 ⌘Space，本地未触发 Spotlight，被控端打开 Spotlight；
- 继续输入 `hello`，被控端 Spotlight 正常显示搜索结果；
- 验证系统快捷键拦截、修饰键转发与文字顺序。

### ⌘Tab

- 本地未切换应用，被控端弹出应用切换器；
- 验证全局系统快捷键在 session tap 层被截获并转发。

### 鼠标点击

- 鼠标移至左上角并左键点击，被控端 Apple 菜单展开；
- 验证归一化坐标映射、`mouseMoved` 与 `leftMouseDown/Up`。

### 连续滚动

服务端日志：

```text
scroll 1 phase=1 momentum=0 dx=0.0 dy=-40.0
scroll 3 phase=2 momentum=0 dx=0.0 dy=-40.0
scroll 10 phase=4 momentum=0 dx=0.0 dy=-40.0
```

`phase=1`（began）、`2`（changed）、`4`（ended）原样到达被控端。

### 退出热键

- 按下 `⌃⌥⌘Q` 后客户端输出 `input: capture stopped sent=...`，立即终止并恢复本地光标。

### 与视频并行

18 秒并行测试输出：

```text
video: decode 60.3fps, recv p95 11.7ms, render p95 27.8ms
input: sent 143 events, server injected 120+
```

视频与输入互不阻塞。

## 4. M2 阶段记录与后续演进

- `⌃↑`：Finder / Terminal 将 Control-Up 视为应用自身快捷键，属于前台应用快捷键占用。
- Secure Input（系统密码框）在启用期间会屏蔽第三方事件捕获，属于 macOS 安全机制限制。
- 触控板多指手势与 Force Touch 未做透传，当前转发离散鼠标与连续滚动事件。
- M2 阶段遗留项的后续状态（详见 [输入连续性专项](2026-10-22-night-run.md)）：双击 `clickCount` 于 2026-10-26（`d50a66c`）补齐；拖拽与 4/5 号侧键已补齐；**Unicode 文本注入未实现**；修饰键失焦归零已补齐。

## 证据分级

- 【事实】滚动 phase 日志（`phase=1/2/4` 原样到达）与 18 秒并行测试输出（`decode 60.3fps`、`recv p95 11.7ms`、`render p95 27.8ms`、`sent 143 events`、`server injected 120+`）均为原始输出摘录。
- 【事实】TCC 权限表记录了两端 Accessibility / Post Event（主控端还有 Input Monitoring）的检查结果；⌘Space、⌘Tab、点击与退出热键为人工操作验证。
- 【推断】`⌃↑` 失效归于前台应用快捷键占用，Secure Input 屏蔽第三方事件捕获属 macOS 安全机制；两者都不是本链路的缺陷。
- 【未经核实】双击 `clickCount` 的补齐（2026-10-26、`d50a66c`）与修饰键归零、拖拽/侧键的验证记录不在本报告内；**Unicode 文本注入至今未实现**，原文“键盘 Unicode 字符同步已全部补齐”的说法不成立。
