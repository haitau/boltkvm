## 2. B1：远端系统动作实现路径对比

| 尝试路径 | 实测结果 |
|---|---|
| 子进程直接通过 AppleScript 调用 System Events | 失败（`-1743`），裸二进制无 Bundle 身份，TCC 不弹授权框 |
| 转发回宿主 App 执行 AppleScript | 仍失败（`-1743`），配合 `AEDeterminePermissionToAutomateTarget` 亦不弹窗 |
| `CGEvent` 注入 `⌃↑` / `⌃↓` | 无效，系统级热键忽略合成按键事件 |
| **`CoreDockSendNotification`（最终方案）** | **成功**：`com.apple.expose.awake`（调度中心）与 `com.apple.showdesktop.awake`（显示桌面）无需任何额外 TCC 授权即可切换开关；`com.apple.expose.front.awake`（App Exposé）调用返回 0 但无视觉效果，故移除该按钮 |

## 3. B4：右上角黑色三角缺口修复

- **根因**：原顶点着色器使用单个超大三角形 `(-1,-1), (3,-1), (-1,3)` 覆盖视口。当按窗口长宽比对顶点乘以缩放系数 `scale < 1` 时，斜边方程变为 `x + y = 2 * scale`，导致画面右上角落在三角形外被裁切出 45° 黑角。
- **修复**：改为标准 4 顶点 Triangle Strip `(-1,-1), (1,-1), (-1,1), (1,1)`。实测 1200×840 窗口渲染 6016×3384 远端画面时四角完整，上下黑边严格对称。
