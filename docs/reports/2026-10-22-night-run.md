## B1：三个远程动作

### 试过、不行的路（都有实测）

| 办法 | 结果 |
|---|---|
| AppleScript 驱动 System Events（helper 里） | `-1743`，TCC 不给裸可执行文件弹框 |
| 转交 app 执行（`@@REMOTE:` 通道） | 仍然 `-1743`，`自动化` 面板始终没有 BoltKVM 条目 |
| `AEDeterminePermissionToAutomateTarget` 主动请求 | 返回 noErr 但无弹框，AppleScript 依旧失败 |
| 请求前 `setActivationPolicy(.regular)` + `activate` | 仍未弹框，仍 `-1743` |
| CGEvent 注入 `⌃↑` | 无效（实测帧率不掉，说明系统没进 Mission Control） |

### 最终方案：CoreDockSendNotification

`HIServices` 的私有符号，用 `dlsym` 解析，缺失时回退到按键注入：

| 动作 | 通知名 | 结果 |
|---|---|---|
| 调度中心 | `com.apple.expose.awake` | 打开；**再点一次关闭**（顺带解决了"点两次不关"） |
| 桌面 | `com.apple.showdesktop.awake` | 显示桌面；再点恢复 |
| App Exposé | `com.apple.expose.front.awake` | 被接受（返回 0）但**无任何效果** |
| App Exposé（备选） | CGEvent `⌃↓` | 无效 |

App Exposé 已移除，代码里留了注释说明。若要恢复，需要 Accessibility 或 Automation
授权——而这两条在本项目当前签名方式下都拿不到。

## B4：右上角黑三角（已修）

根因：渲染用一个超大全屏三角形 `(-1,-1),(3,-1),(-1,3)` 画画面，宽高比适配时按原点
缩放，斜边 `x + y = 2` 变成 `x + y = 2 * scale`；`scale < 1` 时视口右上角落在三角形外，
被裁出一个 45° 黑楔。这也解释了"改窗口大小就消失"——scale 变了。

修法：换成 4 顶点 triangle strip。验证：1200×840 窗口、6016×3384 远端，截图右上角
干净，上下黑边对称（2× 截图里顶部 252–328 行、底部 1679–1753 行）。
